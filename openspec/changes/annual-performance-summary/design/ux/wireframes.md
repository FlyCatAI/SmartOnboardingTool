## 加载态

```text
年度业绩汇总
数据更新于 --
[ 本年度 ] [ 历史汇总 ]

┌────────────┬────────────┐
│ ▒▒▒▒▒▒▒▒▒  │ ▒▒▒▒▒▒▒▒▒  │
│ ▒▒▒▒       │ ▒▒▒▒       │
├────────────┼────────────┤
│ ▒▒▒▒▒▒▒▒▒  │ ▒▒▒▒▒▒▒▒▒  │
│ ▒▒▒▒       │ ▒▒▒▒       │
└────────────┴────────────┘

┌──────────────────────────┐
│ ▒▒▒▒▒▒▒▒▒                │
│ ▒▒▒▒▒▒▒▒▒▒▒▒             │
└──────────────────────────┘
```

Rules:

- Tab 高亮立即切换。
- 骨架替代旧数值，不保留上一个 Tab 的数字。
- P2 骨架独立，不阻塞 P1。

## 错误态

```text
年度业绩汇总
[ 本年度 ] [ 历史汇总 ]

┌──────────────────────────┐
│ 加载失败，点击重试        │
│ [ 重试 ]                  │
└──────────────────────────┘

┌──────────────────────────┐
│ 资产总计                  │
│ 暂无数据                  │
└──────────────────────────┘
```

Rules:

- P1 整体进入错误态，不展示残留数值。
- 点击重试使用当前选中的 `period_type`。
- 连续 3 次失败后文案折叠为「请稍后再来查看」。

## 权限态

```text
┌──────────────────────────────┐
│ 历史业绩                      │
├──────────────────────────────┤
│ 您当前角色暂不支持查看历史业绩页 │
│ [ 返回工作台 ]                │
└──────────────────────────────┘
```

Rules:

- 非客户经理角色不渲染年度业绩汇总区。
- 越权员工号场景展示「无权查看其他客户经理业绩」，随后回退工作台。
