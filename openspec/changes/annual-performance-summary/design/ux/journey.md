# UX Journey - annual-performance-summary

## 三问定方向

| 问题 | 本次确认 |
| --- | --- |
| 平台 | 主平台为移动端小程序；历史业绩页路由为 `/history-performance`。OpenSpec 同时要求桌面端 1440x900 首屏不横向滚动，作为适配验证约束。 |
| 目标 | 易用性优先：客户经理能在季度 / 半年汇报、外出拜访、个人复盘时快速读取本年度与历史汇总业绩；不承担转化型营销页目标。 |
| 约束 | 沿用 rm-mvp-prd 的小程序工作台 / 数据卡片 / 角色权限 / 2 秒 P95 加载约束；采用当前 token 体系占位。未收到正式 WCAG 声明，交互设计按 AA 等效目标处理：可聚焦、可读、错误可恢复、状态不只依赖颜色。 |

## 关键路径

### Path A: 从工作台进入并查看本年度汇总

1. 客户经理打开小程序工作台。
2. 在「我的」入口点击「我的历史业绩」。
3. 系统进入 `/history-performance`，默认 `period_type=current_year`。
4. 页面顶部展示年度业绩汇总区标题、数据更新时间、Tab、4 张 P1 卡片、1 张 P2 资产总计卡片。
5. P1 卡片展示：入网商户、达标商户、有效商户、总收入。
6. 资产总计展示后端值或「暂无数据」，不可点击。

API touchpoints:

- [API] 校验当前会话角色为客户经理；非客户经理进入权限态。
- [API] 拉取年度业绩汇总接口，参数 `period_type=current_year`，返回 `new_merchants`、`qualified`、`active`、`income`、`aum_total`、`updated_at`、数据延迟标记。
- [API] 后端强制校验「请求员工号 = 当前会话员工号」。

### Path B: 切换到历史汇总

1. 用户点击「历史汇总」Tab。
2. Tab 高亮立即切换，不等待接口。
3. P1 卡片进入骨架态，资产总计独立进入骨架态。
4. 系统用 `period_type=all_time` 重新拉取汇总。
5. 返回后替换为历史累计数据。
6. Tab 下方或副标题处出现「自 2026 年起」标注。

API touchpoints:

- [API] 取消上一请求或丢弃旧响应，只渲染最新选中 Tab 对应结果。
- [API] 拉取年度业绩汇总接口，参数 `period_type=all_time`。

### Path C: 从指标卡进入明细

| 指标卡 | 交互 | 目标 | API / 路由说明 |
| --- | --- | --- | --- |
| 入网商户 | 点击 | `/history-performance` | 不携带 `type`；进入或滚动到明细区，按默认入网口径展示。 |
| 达标商户 | 点击 | `/history-performance?type=qualified` | [API] 明细列表按 `qualified` 口径请求或过滤。 |
| 有效商户 | 点击 | `/history-performance?type=active` | [API] 明细列表按 `active` 口径请求或过滤。 |
| 总收入 | 点击 | `/income-details` | 目标页现存，本期不新建；404 / 403 由路由层兜底。 |
| 资产总计 | 不可点击 | 无跳转 | `aum_total=null` 时显示「暂无数据」；hover 提示「开发中」。 |

Route rules:

- `type=qualified` 与 `type=active` 是仅有合法明细口径。
- `type` 缺省、`type=new`、未知值均视为默认入网口径。
- 入网商户卡不再使用 `type=new`。

## 状态矩阵

| 状态 | 触发条件 | UX 表现 | API 标记 |
| --- | --- | --- | --- |
| 首次加载 | 页面进入，请求未返回 | 汇总区结构稳定；P1 四卡骨架；P2 独立骨架；Tab 默认本年度。 | [API] 请求 `period_type=current_year`。 |
| Tab 切换加载 | 用户切换本年度 / 历史汇总 | Tab 立即高亮；当前数值不保留，改为骨架，避免误读。 | [API] 取消旧请求或丢弃旧响应。 |
| 合法零值 | P1 指标均为 0 | 商户类显示 `0`；总收入显示 `¥0.00 元`；卡片不隐藏。 | [API] 后端返回数值 0，而非 null。 |
| AUM 未实现 | `aum_total=null` 或字段缺省 | 资产总计卡片保留，显示「暂无数据」；不报错。 | [API] Q-1 方案 B 可选字段。 |
| AUM 有值 | 后端返回金额 | 资产总计显示元、千分位、2 位小数；注脚「上一日时点值（非日均）」。 | [API] 读取 `aum_total`。 |
| 接口 5xx / 超时 | 汇总接口失败 | P1 整体替换为「加载失败，点击重试」；不展示历史缓存数值。 | [API] 重试原 `period_type`。 |
| 连续失败 | 同一状态连续 3 次失败 | 错误态折叠为「请稍后再来查看」。 | [API] 可停止自动重试，只保留手动重试。 |
| 数据延迟 | 最近可用批次为 T-2 或更早 | 展示可用数据；时间戳旁加「数据延迟更新中」。 | [API] 返回 `updated_at` 与延迟标记。 |
| 非客户经理 | 主管 / 行长 / 其他角色访问 | 不渲染汇总区；展示「您当前角色暂不支持查看历史业绩页」与返回工作台按钮。 | [API] 返回 403 / `E_RM_PERF_FORBIDDEN`。 |
| 越权员工号 | 请求参数员工号与会话不一致 | 展示「无权查看其他客户经理业绩」，自动回退工作台。 | [API] 返回 403 并写审计日志。 |

## 边缘情况

| 场景 | 处理 |
| --- | --- |
| 用户快速连续切换 Tab | 交互只承认最后一次选择；旧请求响应不得覆盖新 Tab 数据。 |
| 用户带 `/history-performance?type=new` 打开 | 忽略 `new`，按默认入网口径展示，不显示错误。 |
| 用户带未知 `type` 打开 | 同上，按默认入网口径展示。 |
| 历史汇总下无历史业绩 | P1 显示合法零值；仍显示「自 2026 年起」。 |
| 客户经理名下商户迁移 | 入网 / 达标 / 有效计数随当前归属迁移；总收入按归属期间分段，不随迁移并入接收方。 |
| `/income-details` 无权限或不存在 | 汇总区不拦截；目标路由统一处理 403 / 404。 |
| 弱网返回慢 | 保持骨架与重试机制；不做端上离线写入或本地数据拼接。 |
