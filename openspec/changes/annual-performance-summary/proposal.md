## Why

客户经理在季度 / 半年节点对外汇报或日常自检时，需要回答两类高频问题：

1. **「今年到现在我累计的展业成绩是什么水平？」**——本年度入网、达标、有效商户数与累计总收入分散在 PC 报表中，外出展业时无法即时查阅。
2. **「我入行以来积累的存量盘子有多大？」**——历史累计数据缺少移动端入口，新人无法直观感受成长、老客户经理无法在拜访新商户时引用历史业绩自证。

业务方提供的《慧展业前端_年度汇总需求_迭代草稿 v0.2》明确将「年度业绩汇总区」作为历史业绩页顶部的固定区域立项。本次提案在原 v1 口径（YTD 金额 / 笔数 / 同比）的基础上**完全替换**为 v2 业务视角（入网 / 达标 / 有效商户 + 总收入 + 资产总计），并落地业务方对 Q1–Q10 的最新回复。

> **范围澄清**：rm-mvp-prd 目前仅覆盖工作台首页「当月绩效完成率」单卡，尚未交付独立的「历史业绩页」。本提案承担两件事：(1) 新增承载汇总区的「历史业绩页」入口与路由；(2) 在其顶部铺设「年度业绩汇总区」。历史明细列表 / 趋势图等能力另立提案。

## What Changes

### 区域结构（v2，全量替换 v1 口径）

- 在客户经理工作台「我的」入口新增**历史业绩页**（v1 仅客户经理本人视角，主管 / 行长视角不在本提案）。
- 历史业绩页**顶部**铺设固定的**年度业绩汇总区**，分为：
  - **顶部 Tab 切换**：`本年度` / `历史汇总`（字段 `period_type` ∈ {`current_year`, `all_time`}），默认高亮「本年度」。
  - **第一行（4 列卡片，P1 必做）**：入网商户数 / 达标商户数 / 有效商户数 / 总收入。
  - **第二行（全宽，P2 占位）**：资产总计（上一日时点值）。
- **不做**同比、月度 / 季度 / 任意区间筛选、主管查看下属、导出、币种切换（与 v1 相比的范围收敛已 BREAKING；v1 已废弃，无下游消费）。

### 与既有提案的关系

- **v1（口径冲突）**：v1 中「YTD 金额 / 笔数 / 同比」已被业务文档 v0.2 **完全替换**；本提案不再保留任何同比 / 笔数指标。
- **同名旧分支 `change/annual-perf-summary`**：先前以 `annual-perf-summary` 命名的草稿基于 v1 口径撰写、未通过审查；本次以新名 `annual-performance-summary` 立项，**不复用其 specs**，原分支视为废弃。
- **rm-mvp-prd**：本提案**不修改** rm-mvp-prd 的 specs / tasks；仅在新 capability `annual-performance-summary` 下新增 Requirement。rm-mvp-prd MVP 上线后再考虑回写「我的」菜单入口的合并方案。

## Impact

- **业务影响**：客户经理在移动端首次具备本年度 / 历史累计业绩自助查询能力；统一了对主管汇报的数据口径。本提案不改变任何绩效核算规则，仅做呈现层聚合。
- **依赖系统 / 数据**：商户状态、入网、收入数据来源已存在（Q-10 业务确认），后续 T-005 技术方案需明确具体上游表与可复用聚合层；AUM 真实聚合（方案 B）可作为后续后端独立任务，前端不阻塞。
- **路由 / 前端契约（Q-7 仓库核查后落地）**：
  - 新增前端路由 `/history-performance`，支持查询参数 `type ∈ {qualified, active}`；`type=new` **不实现**（业务取消）。
  - 新增前端入口卡片 → 跳转契约：入网商户卡 → `/history-performance`（无 `type` 参数）；达标 → `/history-performance?type=qualified`；有效 → `/history-performance?type=active`；总收入 → `/income-details`（现存页面，本期不新建）。
- **数据合规**：年度业绩汇总区仅展示**当前登录客户经理本人**的聚合数据；越权访问其他人业绩需返回 403 并写审计日志。
- **运营影响**：Q-4 商户迁移规则需配套培训物料明确——「转岗后名下商户的入网 / 达标 / 有效计数会迁出，但历史收入不会迁出，接收方接收商户但不接收历史收入」。客服 FAQ 需新增「为什么我的数字和报表对不上」答疑（解释 T+1 节奏）。
- **排期影响**：与 rm-mvp-prd MVP **解耦**，作为独立 capability 立项；本提案仅交付提案材料，不进入设计 / 开发。
